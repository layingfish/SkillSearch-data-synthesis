Skill Rewrite Case Study：SkillGR vs SkillRouter

每个 query 展示 SkillGR 与 SkillRouter 的 top-10 检索结果，以及同一改写模型在 SkillGR / SkillRouter / SkillGR + semantic ID 三类输入下的改写结果和完整提示词。

实验设置

改写模型deepseek-v4-flash，thinking 关闭，temperature 0.3，max_tokens 3000，每个条件采样 1 次
改写输入任务描述 + top-10 候选（每个候选：name、description、body 前 1800 字符）+ 改写指令
四种改写条件SkillGR：SkillGR top-10。SkillRouter：SkillRouter top-10。两者提示词模板完全相同，只是填入的候选不同。
SkillGR + semantic ID（原始码）：SkillGR top-10，每个候选后附 64 位 OPQ 码，并加一段 ID 含义说明。
SkillGR + semantic ID（共享码分组提示）：SkillGR top-10，在候选后附候选之间共享码位数的统计。
两种 SID 条件下，提示词中相对 SkillGR 新增的行用 黄色 标出。
